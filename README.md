README.md for "GJ_OSU_Thesis"
Repository for Gabby John and collaborators 
Purpose: view relevant files and scripts for Oregon State University MS thesis.
-
Overview of folder names:
Climate- micrcoclimate data files from met stations at HJA
Also includes .rmd files for climate data analysis 
DendroAnalyst- .rmd + dendrometer data files for analyzing with DendroAnalyst
documents- presentations, papers, writings, etc. No analysis.
Ecomatik- Ecomatik dendrometer data files and .rmd file for analysis 
misc- miscellaneous files that don't belong anywhere else (e.g., functions)
Misc_analyses- data analyses that don't fit anywhere else 
(e.g., analyses in Excel,BAI [now likely incorrect])
modeling- research-adjacent modeling files and analyses
(e.g., climate toolbox; 3PG [including everything from 3PG class])
novel_code- exclusive spot for new code / functions / scripts I have written
TreeNetProc- .rmd + dendrometer data files for analyzing with TreeNetProc
this includes all files for TOMST dendrometer data
